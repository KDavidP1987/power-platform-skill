# Trigger prompts

Prompts used to check when the skill should and should not load. Should-trigger prompts are the
ones where the method and the traps change the answer; should-not prompts share vocabulary but
need something else.

## Should trigger

1. my canvas app's Save button does nothing in the published app but works fine in Studio preview - no error, nothing written. where do i even start
2. Write a Power Automate flow definition for our solution: when a row in cr4f2_request is updated to Submitted, email the approver and lock the row.
3. I need to add a lookup column to a Dataverse table and use it in a Patch in the canvas app this afternoon - anything I should know before I ship?
4. Can you write a Playwright script that logs into the published Power App and verifies the approve flow actually works after my import?
5. pac solution pack succeeded but the imported solution is missing my cloud flow. what happened?
6. We have 1,400 rows in a Dataverse table to backfill a new column on - write me the migration script (PowerShell, Web API).
7. Here is a .pa.yaml screen - add a ComboBox of customers (8k rows in Dataverse) and a search box that filters the gallery.
8. Set up a new repo for a Power Apps canvas app + Dataverse solution with source control and Claude hooks.
9. my gallery only shows 2000 records even though the filter is delegable on dataverse??
10. Flow ran 900 times in an hour after I turned it on, it updates the same table it triggers on. how do i stop this properly

## Should not trigger

1. Write a DAX measure for year-over-year revenue growth in my Power BI report.
2. Help me build a SharePoint Framework (SPFx) web part in React.
3. Write a Python Playwright test for our Next.js checkout page.
4. Explain the difference between Azure Logic Apps Standard and Consumption pricing.
5. Create an Excel Office Script that formats a table and adds totals.
6. Draft an email to my manager about the Power Platform licensing renewal.
7. Configure an Azure DevOps pipeline to deploy a .NET API to App Service.
8. Write a Dynamics 365 Finance X++ class extension.
